# Paleomorph

Paleomorph is an educational game prototype created for a university course and inspired by the Museu Câmara Cascudo in Natal, Brazil.

Players explore a 3D environment, collect fossil fragments, and assemble prehistoric species. Each body part changes attributes such as sight, aquatic affinity, lightweight, and defense, creating different ways to navigate the course's hazards.

## Play the prototype

[Open Paleomorph in the browser](https://lluc.dev/Paleomorph/)

## Technology

- Unity 2019.4
- C#
- WebGL

## Controls

Drag the screen horizontally to move. Collect rocks and fossil fragments, then choose fossil parts to transform the player and change its abilities.

## Project context

This was a collaborative academic prototype by Lucas Nascimento, Marcos Nóbrega, and Antônio Moreira. It explores how a museum-oriented digital experience can combine local paleontology, discovery, and game mechanics.

The project is preserved as a completed prototype rather than an actively maintained production game.
